產業據點與區位#

  截至2025年12月花蓮都會區（指花蓮市與吉安鄉，亦包含新城鄉嘉禮村）尚在營業的製材廠與建材行約有19間，在空間選址上多集中在里漏部落附近的工業區與田浦車站一帶。標記年份為營業登記年，並非是確切的開業時間（年份資料來源：台灣公司網）。

def year_category(year):
    if year is None:
        return "無年份"
    elif year < 1990:
        return "1990年以前"
    else:
        return "1990年（含）以後"
category_colors = {
    "1990年以前": "green",
    "1990年（含）以後": "red",
    "無年份": "gray"
}

m = folium.Map(
    location=hualien_center,
    zoom_start=13,
    tiles="CartoDB positron",
    control_scale=True 
)

for shop in wood_shops:
    year = shop.get("year")
    category = year_category(year)
    color = category_colors[category]

    popup_text = shop["name"]
    popup_text += f"<br>營業登記年：{year}" if year else "<br>營業登記年：未知"

    folium.Marker(
        location=[shop["lat"], shop["lon"]],
        popup=popup_text,
        icon=folium.Icon(color=color, icon="tree", prefix="fa")
    ).add_to(m)

north_arrow = """
<div style="
    position: fixed;top: 20px;right: 20px;width: 60px;height: 60px;z-index:9999;font-size: 18px;text-align: center;font-weight: bold;color: black;">
    ↑<br>N
</div>
"""
m.get_root().html.add_child(folium.Element(north_arrow))
m

田浦的木業襲產#

  隨著太魯閣林場在1989年正式裁撤，花蓮的木材產業的夕陽也隨之而至。如今依舊有些許製材廠屹立於城市邊緣，致力於在後福特主義的世界中尋得一處棲所。即使當初使產業聚集的區位因素已經不復存在，但依舊能從木材產業的相關據點追溯過往的地理叢結(geographic plexus)。
